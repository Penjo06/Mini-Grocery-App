Mini Grocery Demo app:

offline-first Grocery Delivery application built with Jetpack Compose.
The images of the items are from public online url so make sure to enable mobile internet to see the images, all the other functions are offline.



Features:
User Authentication with Mobile Number and OTP Verification (Fake Otp)
Local OTP Notification System (from the app itself)
Modern UI built entirely with Jetpack Compose
MVVM Architecture
Hilt Dependency Injection
Room Database Integration
Product Search Functionality
Category-based Product Filtering
Responsive Product Grid Layout
Add to Cart Functionality
Dynamic Cart Quantity Management
Automatic Cart Total Calculation
Persistent Cart Storage using Room
Checkout System
Order Summary Screen
Unique Order ID Generation
Estimated Delivery Time Display
Navigation Component Integration
Material 3 Design
State Management with ViewModel
Coil Image Loading
Offline-first Cart Management
Clean and Scalable Project Structure





Tech Stack:
UI: Jetpack Compose (100% Declarative UI)
Architecture: MVVM (Model-View-ViewModel)
Dependency Injection: Hilt (Constructor Injection)
Local Database: Room (with Flow for real-time UI updates)
Navigation: Compose Navigation (with Type-safe arguments)
Image Loading: Coil
Language: Kotlin (Coroutines & Flow)





How to Run:
Follow these steps to get the project running on your local machine:

1. Prerequisites
Android Studio Ladybug (or newer)
JDK 17+

2. Clone the Repository:
git clone https://github.com/Penjo06/Mini-Grocery-App.git

3. Open and Build
Open Android Studio.
Select File > Open and navigate to the cloned folder.
Wait for Gradle to finish syncing.
